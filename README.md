# Mia, the Sun, and the Moon

Children's e-book in English and Spanish by Antonio Rodriguez Martinez. Spanish title: Mia, el Sol y la Luna.

Published at [https://book-sun-and-moon.vercel.app](https://book-sun-and-moon.vercel.app).

## Read it

```bash
pnpm install
pnpm start
```

Then open [http://localhost:3000](http://localhost:3000).

- Arrow keys, space, and swipes turn the page
- Tap the edges of the illustration to go forward or back
- Switch language any time with **EN / ES**
- Use **Read aloud** to hear the page
- Each page has its own URL, such as `/1/park` or `/10/bedtime`

## Build

```bash
pnpm run build
```
