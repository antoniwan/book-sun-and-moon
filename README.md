# Mia, the Sun, and the Moon

A story by Antonio Rodriguez Martinez, written for his daughter Mia and nephew Dario.

English and Spanish. Sunlight, moonlight, birthdays, shadows, and the many sides we all have — just like the moon.

## Read it

```bash
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).

- Arrow keys, space, and swipes turn the page
- Tap the edges of the illustration to go forward or back
- Switch language any time with **EN / ES**
- Use **Read aloud** to hear the page
- Deep-link a page with `#/3`

## Build

```bash
npm run build
```
